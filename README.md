# CapyLulu Windows 桌面宠物

CapyLulu 是一个完全离线运行的 Windows 10/11 x64 桌面宠物。构建时会将 `generated_actions` 中已经完成的动作图内嵌进 EXE；运行时不读取 `raw_images`、外部动作图，也不包含图片生成、更新检查或数据收集功能。

## 运行

发布版本位于：

```text
dist/CapyLulu/CapyLulu.exe
```

直接双击 `CapyLulu.exe` 即可启动。发布时只需发送这一个 EXE 文件。

## 操作

- 左键点击：按顺序播放第 2 行起的互动动画，并显示随机中文气泡。
- 左键拖动：移动桌宠；开始拖动时会中断互动。移动按渲染帧更新，动作速度跟随实际拖动距离，左右换向带防抖滞回。
- 鼠标滚轮：缩放桌宠。
- 右键：更换角色、启动 10 分钟专注计时、透明度、状态切换、注视方式、置顶或退出。
- `Ctrl + Alt + P`：隐藏或呼出桌宠。

## 小互动

- 闲置 35–70 秒后，桌宠会随机播放一段已有互动动作，并显示一句状态对话。
- 开始拖动时先播放提起动作，再按方向切换左右拖动动作；松开后按真实释放速度产生阻尼回弹并反向播放落下动作。
- 支持三种低误触拖动手势：快速横甩、连续左右摇晃、提起后放下。识别后会播放对应反应和对话。
- v2 角色的“注视”可设为“安静”或“跟随”。安静时完全不追踪鼠标；跟随时只在鼠标减速并停留后开始注视，且以最多一个方向档位逐步转向，避免快速追逐鼠标。
- “专注模式”启动 10 分钟倒计时，剩余时间会在桌宠下方每秒更新；重复点击不会重置当前计时，结束时倒计时自动隐藏并弹出提醒。
- “当前状态”可选开心、困困或工作中，分别改变待机节奏、姿态和对话。

## 动作资源

打包时，程序会自动读取 `generated_actions` 中的 `.webp` 和 `.png` 文件并将其内嵌。动作图支持任意实际行列数；第 1 行是待机，后续每行都会作为一组互动循环播放。当前可自动识别以下单帧规格，并允许右侧或底部有少量透明补边：

- 288 × 312；
- 192 × 208；
- 透明背景。

把新的合规动作图放进项目根目录的 `generated_actions` 后，重新执行构建脚本；新生成的单文件 EXE 会在右键“更换角色”中提供它。

动作图旁可放置同名的 `*.pet.json` 动作清单。旧资源不需要清单，仍按“第 1 行待机，其余行互动”兼容播放。v2 资源使用 `8 × 11`、单格 `192 × 208` 的图集：前 9 行是语义动作，后 2 行是从 `000` 向上开始、每隔 `22.5°` 顺时针排列的 16 个注视方向。

## 本地构建

```powershell
.\build.ps1
```

构建脚本使用项目内的 `.dotnet` SDK（如果存在），发布 Windows x64 自包含版本。
