# 已有动作图的形象校准

用于用户提供已有动作图集、多张动作图或序列帧的任务。目标是让这套动作中的人物对齐素材库中对应角色的形象，同时保留原动作。用户明确指定图片只作动作参考或保留原形象时，不启用外观替换。

## 分清动作来源与目标外观

| 来源 | 本次作用 |
| --- | --- |
| 用户明确指定的目标角色与保留项 | 决定身份及必须保留的服装、道具等，优先于其他依据 |
| 输入动作图与已有格式配置 | 提供动作内容、逐帧姿态、朝向、表情阶段、帧序与布局；其中的形态偏差可以纠正 |
| 视觉核实后的素材库形态证据 | 提供头身比、五官结构、口鼻、肢体及连接位置、颜色和材质等目标外观；不提供替换动作 |

先查看完整输入及少量代表帧，覆盖正面、侧面和差异明显的姿态。记录画布尺寸、网格或文件顺序、每行动作、有效帧与空槽、角色朝向及道具左右。优先读取已有 manifest 或配置；没有配置时记录可观察的布局与帧序，不能仅凭行数套用某个运行时契约或编造帧时长。不要把闭眼、张嘴、抬腿等动作阶段当成外观缺陷。

先核实实际输入路径、尺寸和内容指纹。复用历史裁切图或联系图前，确认它们确实派生自本次输入，且裁切坐标、帧序和有效槽位一致；不同编码可比较解码后的 alpha 与可见像素，不能仅凭相同文件名或尺寸复用。缺少派生记录时，从本次原图重新切图通常比追查旧实验更可靠。一次记录布局与来源，后续按需读取摘要，不反复输出完整槽位清单。

## 按角色特征召回并核实证据

按主技能的素材入口与有效性规则读取已有索引。先从代表帧提取可见的稳定特征，再用 `appearance.description` 预筛，按 `appearance.views`、`appearance.visible_parts` 补足所需视角与部位；`appearance.outfit` 用于核对服装差异。有可靠 `character_id` 时可辅助筛选；字段为空时依靠视觉核实，不能凭颜色、服装或相同动作就认定角色身份。

实际打开候选的 `evidence[].file`，核对口鼻轮廓、眼耳位置、头顶装饰、头身比例、肢体粗短与连接位置等共同特征。头部近景与全身图可以互补，但须属于同一目标角色。优先选择清楚、遮挡少、覆盖所需部位的少量图，不把不同相似角色的部件混成一个角色。纯动作标签和 `suggestions` 中的历史改编建议不能作为形象证据。

引用前确认候选仍属于当前素材分组，来源哈希、时间区间与清单一致，证据文件存在且指纹有效；待复核记录先看图复核。具体字段见 [语义记录格式](../../reference-library-semantics/references/annotation-format.md)。仅有过期路径或文本标签不能声称已经核实形象。索引缺失或无命中时，可按主技能流程查看少量未标注候选，不要求先标注全库。

**媒体缺失时一次定位并记录限制。** 先确认当前媒体入口是否存在，再查索引记录的候选路径；不要逐张打开同一个已确认缺失目录。若项目保留证据副本，核对其内容哈希与原证据记录，并实际查看图像；匹配后可作为有来源的历史形态证据使用。记录“副本已核实、源视频／当前分组未复核”，不能将副本说成当前全库召回，也不能把历史生成图当作视频证据。只有关键视角仍缺失时，才按需恢复对应源片；来源或角色身份无法确认时沿用下文的证据不足处理。

没有可靠匹配时，保留原形象，说明暂时缺少哪些依据；只能继续有明确依据的局部修复，不能宣称已对齐素材库。若多个不同角色都合理且无法判定目标，展示少量候选及差别，请用户指定目标；同一角色只有局部证据时，仅纠正有证据的部位，其余保持原状并标明限制。

## 建立校准清单与共用目标角色

在本次生成记录中保存以下三类内容，不写回源素材的语义事实：

- **保留项**：原动作及逐帧关键姿态、表情阶段、朝向、帧序、有效帧、空槽、布局、已知播放时序，以及输入图已有的服装、常驻道具和角色左右关系。除非用户把服装或道具也列为对齐项，否则继续保留；源视频空手不能让输入中的冰淇淋消失。
- **纠正项**：逐项记录“输入偏差 → 目标特征 → 证据图及部位”，例如按全身证据纠正四肢长度，按头部近景纠正口鼻与眼耳位置。区分姿态、透视和表情造成的变化与真正的形态偏差，不做未经核实的全局比例套用。
- **未知或冲突项**：证据缺失、遮挡、视角不符或不同来源不一致的地方，说明保持原状或需要补查的内容。不能把看不到的结构写成确定事实。

从选定证据建立一张共用目标角色图和简短形态约束。已有图足以表达目标时直接复用；否则以原图代表帧和素材库证据制作校准小样，保留原服装、常驻道具及左右关系。只让通过形象核对的小样成为后续各行的基准；不要继续用未经校准的输入帧决定待修复部位，也不要逐行选择不同的目标形象。证据与要求已清楚时直接推进，不为常规小样核对额外等待用户确认。

共用目标图是对证据的改编，不是新的最高形象依据。将原代表帧、素材库证据和目标小样放在一起，确认待修特征确实向素材库靠近，再扩展各行；每行仍对照素材库复核，避免逐次参考生成图积累偏差。衣物与持物已能用现有图和明确约束表达时，不为流程完整而额外生成角色海报。

## 按原动作逐行重绘与验收

把原动作行作为 **edit target**，共用目标角色及视频证据作为外观参考。先写清本行要纠正的部位；只改这些外观特征，不用“相似动作”重新生成一套动作。放大眼睛或调整眼缘时仍保留原帧的睁闭、眼睑遮挡及视线，不能统一为睁眼。更改四肢比例时保留支撑脚、抬脚方向、脚底朝向和重心阶段。

在任务的 `motion-lock.json` 中记录每行最容易丢失的关键帧及观察，例如“第 2 帧双脚收回，第 3 帧前脚抬起”“第 3 帧半闭眼疲惫，第 4 帧闭眼坐下”。这些是从原图读取的约束，缺乏证据时保留未知。共同体型用同姿态的头部／躯干尺度核对；未经确认不要改变人物在原单元格中的整体显示大小。

先用能暴露主要偏差的一行动作验证外观和动作保持情况；涉及多个视角时补查对应姿态，已有合适小样可复用。每次绘图实际附上原动作行、共用目标角色图、相关素材库证据和本行校准清单，明确标注“原图负责动作与布局，目标图及证据负责外观”。保留每帧动作意图、重心变化、方向、关键姿态和道具握持，允许为纠正身体结构调整局部像素，不要求错误轮廓原样不动。

整行连贯重绘，按原槽位组装，不增删动作、不补满原有空槽、不擅自改帧数或重设计收势。没有同名动作视频也可校准：动作已经由输入图提供。沿用主技能的透明处理、对齐、局部返工及停止重试规则。

提示词以稳定形态约束加本行关键阶段为主，重点标明易丢失的闭眼、坐下、换脚、视线和持物侧，不反复改写所有帧。临时多行联系图只用于绘图，显式记录阅读顺序及回填原槽位的映射；它的行间留白和生成位置偏移不属于原动作轨迹。形象与原动作保持分别验收；发现换脚阶段、坐姿或视线被改写时，不用“重绘存在变化”将其判为通过。

小样须在原槽位、原显示比例下通过关键帧对照后才扩展。收到一行结果先核对 `motion-lock.json`，再组装；姿态或表情已变的行直接返工，不期待缩放、对齐或换序修好。对照图与 GIF 对两侧使用相同像素比例，禁止分别裁紧后各自放大到相同高度，这会掩盖缩小和跨行体型变化。

组装后按 [任务记录命令](run-records.md) 运行 `atlas_compare.py compare`。它接受输入图的明确槽位布局，不要求 11 行。尺寸变化超出默认 10% 或位置偏移超过 3 像素时给出复核提示；这些是可调整的诊断阈值，不是角色比例标准。若外观纠正确实需要改变轮廓，验收中记录对应证据；不要为了消除提示自动逐帧缩放。帧数和空槽正确仍可能丢失换脚或疲惫表情，必须另行逐帧目视比较。

验收使用两组对照：与素材库及共用目标角色图比外观，与原图按相同帧序播放比动作。检查跨行角色一致性、局部结构、颜色材质和道具左右，以及动作轨迹、表情阶段、有效帧、空槽、尺寸和透明边缘；有原播放配置时复用其时序。已满足目标的行直接保留，共性的形态偏差则覆盖所有受影响行。

交付校准图集、修复前后对照预览及简短记录，说明采用了哪些形态证据、修正了哪些特征、保留了哪些动作与格式约束，以及尚无证据支持的部分。

将逐行形象、动作保持、尺度、动态播放的结论填入当前对照生成的验收模板，并记录具体观察或失败帧。用 `atlas_compare.py review` 保存结论；工具绑定输入、候选和布局指纹，旧版本的通过结论不能用于新候选。播放未实际检查时保持 `pending`，导出 GIF 本身不等于验收。
