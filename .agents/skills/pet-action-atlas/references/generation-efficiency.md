# 多行生成与局部返工

用于整套生成或已有图集校准。目标是先用小样验证会被所有行复用的决定，后续只重做受到改动影响的部分；不以减少验收换取速度。

## 一次准备，后续复用

- 核实输入、布局、选定证据及绘图工具；实际试运行可用的 Python 与图像依赖，不依赖可能只是系统占位符的 `python`。记录本次可用解释器路径，不把个人机器路径写进技能。
- 一份生成记录维护：输入指纹、布局、参考证据及有效性、共用形态约束、各行关键动作阶段、调用输入与提示词、输出路径、处理参数和验收状态。详细槽位、图片元数据和日志写文件，终端仅输出本次决策需要的摘要。
- 使用 [任务记录工具](run-records.md) 将这些资料保存在同一个 `artifacts/work/<run>/`。每次绘图前保存实际提示词与按顺序附上的图片；结束后关联返回文件或错误，重试记录原因并创建新请求。程序处理自动追加配置快照、行缓存命中、输出指纹及失败事件。
- 优先复用适配当前布局的工具。标准 v2 横条使用 [现有程序](program-processing.md)；其他布局保留原契约，已有适配程序先核实再用。确需补程序时只补缺失的切图／回填能力，不把一次任务脚本原样升级为通用工具。

## 小样必须跑到实际使用尺寸

先用代表行确认四件事：素材库形象是否对齐、原关键姿态是否保持、背景能否可靠处理、缩小组装后是否稳定。任一共性问题未解决时，继续该小样而非批量扩展。额外视角只在它能暴露未覆盖的问题时补做。

**背景由文件数据判定。** 请求真实透明时优先按图像工具规范生成并保留 alpha；收到文件后检查透明像素与 alpha 分布，再看深浅两种底色上的边缘。RGB 棋盘格或全不透明 RGBA 都不能凭显示效果当作透明。不能因为某次失败就永久禁止工具生成透明图。

若本次输出未提供可用 alpha，可选择与角色、服装、道具均不冲突的纯键色，并先验证现有抠图工具能保留眼白、冰淇淋等浅色部位及细小装饰。键色和参数属于本次任务，不固定为绿色或洋红色。背景本身画错可仅修背景；已有纯键色、只是参数或边缘处理有误时，在本地处理，不重新绘图。

**几何先预检再写最终文件。** 对所有有效帧测可见边界、单元格留白和目标锚点，先报告哪一行哪一帧溢出及原因。缩放以同姿态的头部／身体尺度核对，各行保持同一角色体型；同一行使用统一缩放，不因某帧坐下或抬脚而独立放大。不能不断缩小整行来掩盖生成图的体型漂移。

对齐依据原动作或约定的脚底、躯干等锚点。原图包围盒下缘只有在确实代表该锚点时才可使用；挥手、坐下、道具或装饰可能改变包围盒。多行联系图的排版偏移与有意跳跃需分开识别，不能直接把联系图位置差当作动画运动，也不能逐帧自动居中抹去原轨迹。

## 分阶段复用，避免整套重跑

处理工具应区分这些依赖；已有工具具备缓存时直接使用，简单任务可保存中间文件达到同样目的，不必重建缓存框架：

| 阶段 | 复用依据 | 哪种改变需要重做 |
| --- | --- | --- |
| 绘图行 | 原动作、形态依据、提示词与工具设置 | 该行画面错误，或共用角色标准变化 |
| 透明行图 | 绘图文件内容、背景参数、处理工具版本 | 源像素、抠图参数或实现变化 |
| 切图与对齐 | 透明行图、布局、尺度、锚点 | 对应几何参数或实现变化 |
| 拼接与预览 | 处理后的帧、槽位、预览时长 | 帧、布局或播放配置变化 |

仅改对齐参数时复用透明行图；仅改预览速度时不重抠图、不重绘。缓存命中依据内容和参数，不能只看文件存在。失败输出保留诊断但不作为已通过缓存。先全部预检，成功组装并检查后再更新交付路径，避免在中途把不完整版本复制成最终文件。

角色标准及完整处理路径稳定后，可少量并发独立的绘图行；为每行保存请求与结果，逐一检查成功或失败。反馈显示共享缺陷时暂停扩展，定位形态依据、提示词或处理问题。不要为提高并发而省略实际参考图片，也不要预先启动依赖尚未通过小样的行。

## 区分通过了什么

- 分别记录结构检查、形象检查、原动作保持、动态播放检查。帧数正确和生成了预览文件，不代表已经看过动画；静帧也不能证明无抖动、无跨行尺度跳变。
- 原图校准另行记录尺度检查。使用固定像素比例的输入／输出对照，关键帧先验睁闭眼、视线、支撑脚和坐姿；结构报告为 pass 而任一视觉项失败的候选不能交付。
- WebP 无损回读检查分别比较 alpha 和可见像素；完全透明像素的 RGB 编码变化不必触发重绘。
- 只修对应问题：形象／动作错误修绘图行，纯背景问题修背景或抠图，对齐／溢出修几何，时序／预览错误修播放配置。共性形象错误需检查所有受影响行，不能因行已生成而直接保留。
- 播放能力受限时保留候选、说明动态验收未完成；不能把建立 HTML 或导出动画当作播放验收。没有原时长时使用明确标注的复查速度，不宣称还原原始节奏。
- 调用时记录起止时间、重试原因与缓存命中；收尾报告实际完成与未验收部分。没有前后基准测量时，只说明消除了哪些重复工作，不承诺固定提速比例。
