# 素材库语义标注

把实际看到的源素材记录成可检索的信息，供后续独立查找动作和形态证据。使用当前具备视觉理解能力的模型查看素材；程序负责枚举、指纹、合并和校验，不需要为本任务另建模型服务。

## 输入与范围

默认从项目根目录的 `reference-library/actions/index.json` 读取当前视频分组，再读组和片段的 `manifest.json`。以索引中的当前分组为准，不递归把保留的历史版本重复建库。只有原视频时先使用现有 [提取工具](../../../video-actions/README.md)。

用户指定片段时只处理这些片段；请求建立或补齐整个库时覆盖全部当前候选。复用未变化的已有标注，只处理新增、失效或明确要求修正的记录。被锁定的人工记录保留，输入变化时报告需要复核。

首次写入前读取 [记录格式](references/annotation-format.md)。默认输出 `reference-library/semantics/index.jsonl`，与提取程序生成的索引分开保存；只有实际产生标注时才建立输出。先检查已有记录与库的实际能力，不假定存在自动标签或搜索命令。

## 理解素材

1. **先看摘要。** 按小批查看候选的八帧摘要与时间戳，并明确每组对应哪个片段。不同候选分别标注，不混合镜头、服装或角色；不要一次把整个库的图片塞入上下文。
2. **动作语义。** 用简短中文描述可见的动作顺序，给出可复用的动作模式与少量常用标签，例如“侧倾、探头、收回”。记录道具依赖、可用肢体、位移和姿态等与动作选择有关的条件。标签不绑定运行时行名称；气质或用途推测与观察事实分开。
3. **形态语义。** 独立记录看得清的外观、视角、身体部位、服装和遮挡，允许没有明显动作的素材仍提供形态证据。仅在已有可靠角色标识时填写角色 ID；不能凭颜色或相似服装认定跨视频身份，也不能把源片的衣服、道具或未见结构升级为目标角色约束。
4. **歧义才深读。** 摘要不能说明的动作方向、起止姿态或遮挡，按需要查看对应连续帧；支持视频理解时也可看预览。记录实际查看的证据。看不清则保留未知和原因，不为完整字段猜测；不凭摘要宣称动作可无缝循环。

候选不等于完整动作。源片中的离场、近景裁切、道具遮挡和镜头缩放照实记录；提取器的颜色跟踪提示只是待核对信息，不能直接转成模型确认的事实。动作抽象保留源动作的实质，改编建议放入独立字段，不写成视频已经表演过的动作。

## 缓存与交付

用程序读取来源、计算片段键与证据指纹，按格式合并 JSONL，检查类型、唯一性、时间范围和证据路径；这些值不要交给模型猜。没有读取到视觉素材的片段记录为失败或待处理，不填充虚构标签。

保存实际完成的条目，失败只影响对应片段，不清空旧索引。只重试失败条目；同一失败针对性重试一次仍未解决时记录原因，继续其他片段。保留人工修正和未纳入本次范围的记录；源片切分改变时标记旧记录过期，不套用到新的时间范围。

交付语义索引路径、完成/复用/待复核/失败数量，以及少量标注例子。用本次素材支持的查询检查动作描述和形态描述能否分别找到对应条目；这只验证记录可用性，不声称已经实现搜索服务或完成图集视觉验收。

下游使用原则：动作无匹配时可以自由设计；固定角色图与已确认的身体约束始终由生成任务独立提供。查找视角或身体部位不受动作名称限制。
